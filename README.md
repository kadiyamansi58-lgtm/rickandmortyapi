# Rick and Morty API

A responsive React JS application that displays characters from the Rick and Morty animated series.

## Features
- Display character details
- Fetch data from Rick and Morty API
- Responsive design
- Character cards

## Technologies Used
- React JS
- JavaScript
- HTML
- CSS
- Rick and Morty API

## Installation

1. Clone this repository.
2. Run `npm install`.
3. Run `npm start`.
